# Card-Collection

The Card is a simple web component created using HTML and CSS. It displays a  code , a heading, and a short description inside a neatly designed card. The card is centered on the webpage using CSS Flexbox, providing a clean and responsive layout. CSS is used to style the card with padding, rounded corners, spacing, and appropriate font sizes to improve its appearance and readability. This project helps beginners understand the basics of webpage structure, layout design, and styling, making it a good introduction to front-end web development.
